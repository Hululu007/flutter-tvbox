「我的」 · 历史 / 收藏 / 设置 都收进来了

tab 从 5 个减到 4 个

原来：首页 / 直播 / 历史 / 收藏 / 设置
现在：首页 / 短剧 / 直播 / 我的

历史和收藏使用频率低，占两个常驻位不划算；设置更是一个月点不到一次。 全收进「我的」之后，首页和短剧这两个高频入口才有位置。

选中态换了逻辑

之前是实心渐变胶囊 + 白字。底部导航常驻，实心块会一直抢注意力。
改成参考稿那样：accent 13% 透明度的浅蓝底 + 蓝色图标 + 蓝色文字，未选中降到 textTertiary。
图标也从 18px 放大到 22px，视觉重量更接近参考图。

短剧页的数据从哪来

不单独配置源 —— 从当前主页源的分类表里挑名字带「短剧」的那个，找不到就回落第一个分类。
这样换源之后不用另外维护一套映射。翻页、下拉刷新、去重都做了。
